## Delivered core workflows

**Decision Engine.** The new copilot analysis form retrieves the current owned revision, uses the existing bounded interpreter/provider adapter, asks for clarification when no defensible command exists and generates structured cards with saved evidence, operational effects, trade-offs, assumptions, assessment and approval requirement. Supported interpretation now includes the brief's natural-language budget and venue-increase phrasing. Financial alternatives reuse `simulate`; budget reductions reuse the existing Rescue allowance allocator, preserving recorded exposure and reserve. Cards distinguish total budget/allowances from projected recorded costs: a lower allowance does not pretend to negotiate savings. Advisory cards show actual warnings, recorded obligations and open milestones; no payment due dates or market savings are invented.

Analysis is read-only. **Save isolated preview for review** calls the original scenario API and opens its original comparison/approval component. It cannot apply, bypass feasibility, rebase stale revisions or authorize an expense mutation. All previous transaction, date/revision re-simulation, rollback and replay protections remain.

**Quote Analyzer.** There was no document parser to extend. The delivered supported workflow is paste or select bounded UTF-8 `.txt` with explicit labels: Vendor, Service, Currency, Item (`description | quantity | unit price`), Subtotal, Tax, Fee, All-in total, Deposit, Payment (`YYYY-MM-DD | amount`), Cancellation, Overtime, Valid until and Inclusions. Unsupported labels, duplicate ambiguous fields, invalid amounts/dates, mismatched subtotals/totals/currencies/services, expired validity, excessive deposits/payment schedules and missing costs are visible. Source text and exact line evidence accompany extracted values. Multiple sources in one selected service category can be compared with totals, charges, deposit, terms and missing facts; no cheapest-vendor ranking. Each source retains its own currency, with no implied FX conversion. Mismatched/unknown currency cannot be recorded.

The server rejects unsupported filename/MIME/signatures, path-like names, NUL/binary-looking content and limits text to 6,000 characters, 10,000 UTF-8 bytes, 80 lines and 400 characters per line, under the existing 20KB actual-body cap. Files are read locally by the browser into the bounded JSON workflow; no filesystem upload, PDF/ZIP/OCR parser or multipart dependency exists. Document text never reaches an AI provider. Numbers validate through the existing Money/Quantity rules and `ExpenseRecord.line_total`; quote reconciliation does not replace the event ledger.

**Record reviewed choice** requires strict explicit approval, owned/current event, matching category/vendor and a selected existing expense when its service is already represented. It records a quote or explicitly chosen full commitment through existing reconciliation and CAS persistence. Existing notes, paid amounts and unreleased commitments are preserved; quoted deposits never become paid transactions. A request UUID and exact-payload history digest support replay without duplicate records/revisions; changed-payload retry conflicts. Concurrent CAS conflicts fail rather than double-write. Full raw quotation/payment terms remain in the current analysis, not a document vault: review provenance uses remaining space in the existing 500-character notes field, plus a saved request/payload digest in history. Existing notes take priority if that field is full. Reselect the original file after reload for full source comparison.

**Design Studio.** Ideas now contains an editable brief, optional validated hex palette, three local CSS mood boards, structured floral/light/decor/table/invitation/atmosphere directions and links to actual saved allowances/exposure. Optional Gemini only orders three allowed styles through strict output validation; the recipes/visuals remain built-in and are labeled accordingly. Invalid/duplicate/extra model output fails to local ordering. This is inspiration, not photography, a priced design, verified stock or a booking. Quote navigation connects the direction to the existing ledger workflow before money changes.

Saving a preferred concept requires explicit confirmation and current ownership/revision. The additive `design_preferences` table holds at most one concept snapshot per event with its own `format_version=1`, FK cascade and owner. Its migration is lazy on the first confirmed save, within `BEGIN IMMEDIATE`; original workspace/scenario tables, migrations, user_version 2 and response schemas remain untouched. Saved notes/theme/money are not overwritten. A later event revision marks its budget snapshot stale. Unsupported/corrupt design formats fail closed without replacement. The migration, update rollback, deletion cascade, isolation and browser/server restart were tested on temporary existing schema-2 databases.

**Timeline intelligence.** The existing generator, completion checklists, calendar export and date scenarios remain. A new read-only panel accepts an open saved task, delay and explicit prerequisite buffer. It traverses recorded links, checks original dependency consistency, shows original/proposed deadlines and flags event-date crossings. Missing links are disclosed; completed/event tasks and unknown IDs are rejected. No task owners, durations, supplier capacity or critical path is invented. `can_apply` is always false. A link leads to the existing Rescue/date-alternative flow for separately reviewed changes.
